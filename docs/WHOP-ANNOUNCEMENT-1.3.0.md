187N Agent HQ staat klaar. Gratis voor iedereen hier.

Het is je eigen AI-hoofdkantoor, als app op je Mac of pc. Gebouwd op het HQ waar ik zelf mee werk. Je agents draaien op je eigen abonnement van Claude Code, Codex of Hermes Agent.

Wat erin zit:
- Marketing: Studio, Creator Lab (zie welke hooks en structuren bij een creator het best scoren), carrousels en stories
- Voice: praat met je Chief of Staff en krijg hardop antwoord
- Je second brain: koppel je Obsidian-vault of begin een nieuwe
- Je eigen tools: apps via Composio, MCP-servers, API-keys en skills

Downloaden (zie de bijlagen):
- Mac, macOS 13 of nieuwer: 187N Agent HQ 1.3.0.dmg
- Windows 10 of 11 (64-bit): 187N Agent HQ Setup 1.3.0.exe. Windows is nog beta.

Bij allebei zit een Read Me First (pdf). Lees die even, dan ben je in een minuut of tien klaar met installeren en Setup.

De eerste keer openen krijg je een waarschuwing. Dat hoort zo: de app is nog niet ondertekend bij Apple en Microsoft. Op de Mac ga je naar System Settings > Privacy & Security en klik je op Open Anyway (op macOS 13 of 14: rechtsklik op de app > Open). Op Windows klik je op More info en dan op Run anyway. Dat doe je maar één keer.

Wat kost het?
De app zelf niks. Je hebt wel een AI-abonnement nodig (Claude, ChatGPT voor Codex, of Hermes Agent). ElevenLabs, Apify, Composio en de rest zijn optioneel en lopen via je eigen account. Een Apify-run laat altijd eerst zien wat hij maximaal kost en start pas als jij klikt.

Je data blijft op je eigen computer. Je keys staan versleuteld opgeslagen: op de Mac in de Keychain, op Windows met je Windows-account.
